# Kontext — Das Gehirn

Dieses Modul füllt die vier Kontext-Dateien mit echtem Inhalt über dich und dein Business.

**Was es tut:**
- Geführtes Interview über dein Business, deine Rolle, deine Strategie und deine Zahlen
- Füllt `context/business-info.md`, `personal-info.md`, `strategy.md`, `current-data.md`

**Voraussetzungen:** Absicherung muss eingerichtet sein.

**Danach:** `/prime` — dein Mitarbeiter kennt dann dein Business.
